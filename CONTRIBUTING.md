# Contributing

Bug reports and questions are welcome as [issues](https://github.com/caldrix-ai/models/issues/new).

This repository is generated from models.js's private source, and every change made here is overwritten by the next
update, so pull requests are not accepted. If you found a mistake in the code or the docs, open an issue and we will
fix it at the source.

A useful bug report has:

- the version of `@caldrix-ai/models` (and of `@caldrix-ai/caldrix`, if you use it through caldrix.js);
- the browser and its version, and the operating system;
- the Hugging Face repo and revision you named, or the name of the made model;
- the code you ran, and the `ModelsError`'s `kind` and message;
- what you expected, and what happened instead.

Do not paste access tokens or the contents of private repos.
